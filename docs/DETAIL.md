# 书架 / Bookshelf

DSH 右侧栏里的一个阅读标签页。窗口一失焦，右栏整列收起；回来用原生展开按钮接上，还是同一章、同一个滚动位置。

## 它解决什么

小公司上班，屏幕上总得是「工作」。这个插件不假装自己在做别的事——它只让那一列在你走开的时候消失，回来再出现。没有托盘、悬浮窗、热键，也没有需要记的快捷键：切走就是关掉。

## 两个入口

- **右侧栏 → 开始（罗盘页）→ 「书架」卡片**：和「工作区文件 / 新建终端 / 浏览器」排在一起。点开就是一个真正的右栏标签页，可拖动、分屏、浮动，关掉后从同一张卡片再开。
- **设置 → 通用 → 书架 → 打开**：同一个标签页的第二条入口。

标签页布局按会话记住，下次打开右栏还在原处。

## 失焦收起

触发条件只有一个：**书架这个标签页正在右栏里显示着**。这时

- 窗口失焦（Alt+Tab、点到别的应用）
- 标签页被切到后台
- 窗口最小化 / 页面隐藏

都会立刻收起整个右栏，而不是只把阅读器藏起来。收起后还会在 120ms、400ms、1200ms 各补一次，防止浏览器在后台窗口里把这次渲染压住；如果你已经回来了就不打扰。

它不会去动别的面板：没开书架标签页时，切窗口不会碰右栏。

## 阅读页

仿的是开源阅读器 [legado / 阅读](https://github.com/gedoor/legado) 的排版规矩：

- 顶栏：书名 + `18 / 793`；底栏：`‹ 上一章｜目录｜章号输入｜/ 总数｜Aa｜下一章 ›`。两条栏都占布局，不压在正文上。
- 章标题在正文里，不会被顶栏盖住；正文末尾还有一颗「下一章 ›」，全书最后一章显示「— 全书完 —」。
- 底栏常驻，不用先点屏幕中间呼出工具栏。
- 最底下一条 2px 的进度线，显示整本书读到哪。
- 「目录」支持按章名搜索、高亮当前章、点一下跳过去；`Esc` 先关目录、再关阅读设置。
- 进度按书保存在本机，下次打开从原处接着读。

### 点击翻页（可选）

`Aa` →「点击翻页」，**默认关**，滚轮党和触摸板不受影响。打开后：点左边 1/3 往回翻一屏（已经在顶部则上一章），点右边 1/3 往后（到底则下一章）；有文字被选中时不会误触。

## 阅读设置

底栏 `Aa` 展开，全部即时生效并存在本机：

| 项 | 取值 |
|---|---|
| 字号 | 15 / 17 / 19 / 21 / 23 / 25 |
| 行距 | 1.6 / 1.8 / 2.0 / 2.2 |
| 段距 | 0 / 0.4 / 0.8 / 1.2 em |
| 首行缩进 | 开 / 关 |
| 字体 | 系统 / 宋体 / 楷体 |
| 纸张 | 跟随主题 / 米黄 / 纯白 / 浅绿 / 浅粉 / 夜间 |

## 书从哪来

插件**不带任何书源**：书源规则变得比插件还快，内置一套等于内置一份过期的东西。书由 AI 现找现下，或者你自己给。

| 方式 | 怎么用 |
|---|---|
| 让 AI 找 | 「帮我找《书名》，下到书架」。AI 自己搜、自己找可下载的 TXT/EPUB 或章节页，再调工具入库 |
| 本地文件 | 给 AI 一个路径：`.txt` / `.epub` / 整本书的单文件阅读页 `.html`（按它内嵌的章节数据整体导入） |
| 网页 | 一个当前页的网址，或一个 `.epub` 直链 |
| 正文 | 把已经拿到的正文直接导入，含「第X章」会自动分章 |
| dsh-novel 缓存 | 装过 [dsh-novel](https://github.com/xrn1997/dsh-novel) 的话，书架底部会多一个「从 dsh-novel 导入」，把它下好的缓存整本搬过来（标题、目录都保留） |

没装 dsh-novel 也完全能用：那张按钮不会出现，其余路径不受影响。

## 长书不用等

整本下载不是一次抓完的：**先抓前 20 章**（约一分多钟）让你立刻开读，剩下的排进后台队列——

- 每 **10 秒**一章（人读一章约 8 分钟，队列始终领先 48 倍以上）；
- 每 **50 章**休息 90 秒；
- 撞到站点限流就按它的冷却 70 秒重试，连续失败 4 次才放弃那一章；
- 队列写在磁盘上，**DSH 重启会自己接着跑**；
- 随时可以问「后台下到哪了」，或者让它暂停 / 继续 / 取消。

## 抓取与正文清洗

- 请求之间共享一个 **5 秒**间隔（跨多次调用也生效），不并发。
- 撞到 `400 / 403 / 429 / 503` 会先冷却 70 秒重试一次；再失败就停下，把还没抓的 URL 原样还回来，不会硬撞封禁。
- 已入库的章节按章名跳过，所以重复调用是安全续传：不重复、不乱序、不动已读进度。
- 正文会过滤站点导航（首页/目录/上一章/字体+ 之类），也会处理一种常见的防盗水印——把别的书名粘在句尾标点前（`…骚动武动乾坤。`）。判定很保守：同一词组要在一章里重复至少 10 次、密度超过 4‰ 才动手，正常行文里重复出现的句子不会被误删。

## 数据与隐私

- 全部数据在本机 `~/.dsh/moyu-novel/`：`books/<id>/meta.json` 存目录和进度，`books/<id>/ch/NNNN.txt` 存正文，`queue/` 存后台队列（跑完即删）。
- **不上报任何东西**，不向第三方服务器发请求；抓取只发生在你或 AI 明确要求导入/下载时。
- 纯 JS，零第三方依赖，只用 Node 内置模块；没有构建步骤。
- 本地接口挂在 DSH 自己的 Web 服务上（`/moyu-novel/api/*`），只给本机同源页面用，跨站请求直接 403。

## 安装

DSH → 插件 → 添加插件，安装规格填下面任一条：

```
https://github.com/oldc12138/dsh-moyu-novel/releases/download/v1.0.0/dsh-moyu-novel-1.0.0.tgz
```

```
https://raw.githubusercontent.com/oldc12138/dsh-moyu-novel/main/dist/dsh-moyu-novel-1.0.0.tgz
```

也可以把仓库下下来，填本地目录：`link:D:/tools/dsh-moyu-novel`。装完刷新页面，右栏「开始」页就有「书架」。

## 已知限制

- **不是书源管理器**：没有书城、没有搜索源，也没有自动追更。
- **EPUB**：只处理无 DRM 的版本（ZIP + OPF spine）；加密字体、固定版式不处理。
- **进度**只存本机，换设备不同步。
- 只有书架标签页显示时，失焦才会收起右栏；这是刻意的，免得它去动你在用的终端或文件面板。
- 需要 DSH 能装插件（本体版本要支持 bundle 安装）。

## AI 侧的工具

| 工具 | 作用 |
|---|---|
| `moyu_novel_library` | 列书架、看进度 |
| `moyu_novel_import` | 导入：`file` / `url` / `text` / `cache`（dsh-novel 缓存） |
| `moyu_novel_download` | 按章节 URL 抓取；默认先抓前 20 章，其余排进后台队列 |
| `moyu_novel_prefetch` | 看后台进度，暂停 / 继续 / 取消 |
| `moyu_novel_read` | 读某一章（核对、摘录） |
| `moyu_novel_remove` | 删书（连同本地章节文件） |

## 为什么没有老板键

老板键要记一个键，按错的时候反而最显眼。这里只做一件事：窗口失焦，右栏消失。你不需要记得任何东西。

# 书架 / Bookshelf

## 它做什么

一个注册到 DSH **右侧栏**里的阅读标签页，和「工作区文件 / 浏览器 / 终端」排在同一个「开始」页上：

- **入口就是右侧栏的那张卡片**：打开右侧栏 → 开始（罗盘页）→ **书架**。也可以在 设置 → 通用 → 书架 打开。
- **窗口一失焦，右侧栏整个收起**——Alt+Tab 切走、切到别的应用、标签页被切走，内容立刻消失；切回来只看到对话。
- **切回来一键接上**：用 DSH 自带的右侧栏展开按钮（对话右上角）或它的快捷键把右栏拉回来，书架标签页还在，回到上次那一章那一屏。标签页布局按会话记忆，不用再翻设置。
- 没有热键、没有托盘图标、没有常驻悬浮窗。
- 读的是本地书：书存在 `~/.dsh/moyu-novel/`，断网也能看；阅读进度自动保存。

## 怎么进

**右侧栏 → 开始 → 书架**：和原生标签页一样，可以拖动、分屏、浮动、关掉；关掉后从同一个卡片再开。
**设置 → 通用 → 书架** 是第二条入口（会给同一标签页）。

## 阅读页（照「阅读 / legado」的规矩做的）

- **两条栏都占布局、不压正文**：顶栏是书名 + `234 / 793`，底栏是 `‹ 上一章｜目录｜章号｜Aa｜下一章 ›`；章标题在正文里，不会被盖住。
- **章末还有一颗按钮**：正文最后一行下面直接是「下一章 ›」（全书最后一章显示「— 全书完 —」）。
- **点击翻页可选**：`Aa` →「点击翻页」开/关，**默认关**（滚轮 / 触摸板照常滚）。打开后：点**左边 1/3** 往回翻一屏（到顶则上一章）、点**右边 1/3** 往后（到底则下一章）；选中文字时不会误触。
- **底部细进度线**常驻，显示整本书的进度。

## 阅读设置

底栏 `Aa` 展开，全部即时生效、存在本机：

| 项 | 取值 |
|---|---|
| 字号 | 15 / 17 / 19 / 21 / 23 / 25 |
| 行距 | 1.6 / 1.8 / 2.0 / 2.2 |
| 段距 | 0 / 0.4 / 0.8 / 1.2 em |
| 首行缩进 | 开 / 关 |
| 字体 | 系统 / 宋体 / 楷体 |
| 纸张 | 跟随主题 / 米黄 / 纯白 / 浅绿 / 浅粉 / **夜间** |

底栏「目录」打开章节列表：**可搜索章名**、高亮当前章、点一下跳过去；`Esc` 先关目录、再关阅读设置。

## 书从哪来

插件自己不带任何书源——书源规则易变，与其内置一套会过期的爬虫，不如让 AI 现找现下：

| 方式 | 怎么用 |
|---|---|
| 让 AI 找书 | 对 AI 说：「帮我找《书名》，下到书架」。AI 会用网络搜索、找到可下载的 TXT/EPUB 或章节页，然后调用插件工具入库 |
| 从 dsh-novel 搬 | 抽屉底部「从 dsh-novel 导入」：把那个插件已经缓存好的书整本搬过来（标题、目录都保留；没缓存的章节标「尚未缓存」） |
| 本地文件 | 告诉 AI 文件路径，或直接调用工具 `moyu_novel_import`（`source: file`，支持 `.txt` / `.epub` / `.html`；单文件阅读页按它内嵌的章节数据整体导入） |
| 网页 | `source: url`：整本书的单页正文，或一个 `.epub` 直链 |
| 正文 | `source: text`：把已抓到的正文直接导入，含「第X章」会自动分章 |

AI 侧的工具：`moyu_novel_library`（列书）、`moyu_novel_import`（导入）、`moyu_novel_download`（按章节 URL 抓取，默认先抓前 20 章、其余排进后台队列）、`moyu_novel_prefetch`（看后台进度、暂停/继续/取消）、`moyu_novel_read`（读某一章核对）、`moyu_novel_remove`（删书）。

## 边界与注意事项

- **只读、只看、只收起**：插件不向任何服务器上报内容；抓取只发生在你或 AI 明确要求导入/下载时。
- **不是书源管理器**：没有「书城」和「搜索源」。想看某个站的书，要么走 dsh-novel 那套书源，要么让 AI 现找。
- **EPUB**：支持无 DRM 的 EPUB（ZIP + OPF spine 解析）；DRM、加密字体、固定版式不处理。
- **进度**按书保存，最多只记到章内滚动比例；换设备不互通。
- **右栏联动**：只有在抽屉开着时失焦，才会顺手收起右侧栏（例如你先在右栏里预览了一个 HTML 阅读页）；抽屉没开时切窗口不会碰别的面板。
- **本地 HTTP 接口**挂在 DSH 自己的 Web 服务上（`/moyu-novel/api/*`），只有本机同源页面会用到；关掉 DSH 就没有了。
- 安装后需要**新开一个会话**；客户端产物在页面刷新时加载。

## 为什么没有老板键

老板键要记一个键，按错了反而显眼。这里只做两件事：**入口藏进设置**，**窗口失去焦点内容就消失**。你不需要记得任何东西——切走就是关掉。
